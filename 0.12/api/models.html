Models API#

fastapi_restly.models provides ModelDefaults, which adds Restly’s defaults to your own declarative base, and the model mixins IDMixin and TimestampsMixin. Models shows how to use them. It also provides two cascades for relationships on an async session, CASCADE_ALL_ASYNC and CASCADE_ALL_DELETE_ORPHAN_ASYNC.

fastapi_restly.models.CASCADE_ALL_ASYNC = 'save-update, merge, delete, expunge'#

The cascade "all" without "refresh-expire", for relationship(cascade=...) on an async session: "save-update, merge, delete, expunge". With "all", your own session.refresh(obj) also expires the related objects. On an async session, the next read of one can then raise MissingGreenlet. Restly’s own save after a write refreshes by attribute name and does not cascade, so "all" is safe on Restly’s write paths. See SQLAlchemy’s Preventing Implicit IO when Using AsyncSession.

fastapi_restly.models.CASCADE_ALL_DELETE_ORPHAN_ASYNC = 'save-update, merge, delete, expunge, delete-orphan'#

CASCADE_ALL_ASYNC with "delete-orphan": the cascade "all, delete-orphan" without "refresh-expire".

class fastapi_restly.models.IDMixin#

Bases: MappedAsDataclass

Dataclass mixin adding an auto-incrementing integer id primary key.

Made for models on a base with ModelDefaults. On another base, SQLAlchemy makes each model that uses it a dataclass.

id: Mapped[int] = mapped_column(...)#

The primary key: an integer that the database generates when it inserts the row. The constructor does not take it, and it is None until the session flushes the new object.

class fastapi_restly.models.ModelDefaults#

Bases: AsyncAttrs, MappedAsDataclass

Restly’s defaults for SQLAlchemy models, for your own declarative base.

Add it to your base class, before DeclarativeBase:

class Base(fr.ModelDefaults, DeclarativeBase):
    pass

Base stays yours: it has its own registry and MetaData, as with any DeclarativeBase. Your models get:

  • A dataclass constructor that takes keyword arguments only. Type checkers accept a required field after a field with a default.

  • Equality by identity, as for any SQLAlchemy model: two objects are equal only when they are the same object. So a model object can go in a set, and comparing objects never loads a relationship.

  • A repr that shows the loaded columns and never loads anything, so it works in async code. Pass repr=True on a model for the dataclass repr, which reads every field.

  • A table name in snake_case from the class name: BlogPost gets blog_post. Set __tablename__ on a model to choose another name.

  • Mapped[datetime] as DateTime(timezone=True). Use mapped_column(DateTime()) for a column without a time zone.

  • An enum.Enum as a string column of up to 64 characters that stores the member’s name, not a database enum type. A new member then needs no migration.

  • awaitable_attrs from SQLAlchemy’s AsyncAttrs. An unloaded attribute can then be reached from plain async code, await obj.awaitable_attrs.items, where a bare obj.items would raise MissingGreenlet. Views eager-load what the response class names, so this is for the code that runs outside that: an after_action_commit hook, a custom business method.

Declare your own metadata and type_annotation_map on Base as SQLAlchemy documents them. Your type entries win over Restly’s.

Set dataclass options such as eq=True on a model, not on Base. SQLAlchemy takes the options from the first dataclass class in a model’s bases, which is often IDMixin, so options on Base would apply to some models only. Base with options raises RestlyConfigurationError.

For the same reason, a dataclass mixin of your own declares the options of fr.IDMixin: class Stamped(MappedAsDataclass, kw_only=True, eq=False, repr=False). Without eq=False, a model with the mixin compares fields, and comparing two objects can load a relationship. Without repr=False, the model gets a dataclass repr instead of this one, and that repr can load a relationship too. Such a model raises RestlyConfigurationError, unless it passes eq=True or repr=True itself, or writes its own __eq__ or __repr__.

class fastapi_restly.models.TimestampsMixin#

Bases: MappedAsDataclass

Dataclass mixin that adds created_at and updated_at, in UTC.

Made for models on a base with ModelDefaults. On another base, SQLAlchemy makes each model that uses it a dataclass.

created_at: Mapped[datetime] = mapped_column(...)#

When the row was created, in UTC. The model sets it to the current time when you create the object. The database sets it when SQL that leaves it out inserts a row.

updated_at: Mapped[datetime] = mapped_column(...)#

When the row last changed, in UTC. The model sets it when you create the object, and again in each UPDATE that SQLAlchemy runs for the row. The database sets it when SQL that leaves it out inserts a row.

See also

Models shows how to add Restly’s defaults to your own declarative base and how to change one. Use your existing models shows Restly views on the models you already have.
