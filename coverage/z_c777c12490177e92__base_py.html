205class Action: 

206 """The names of the five CRUD actions: the ``action`` that ``authorize`` 

207 gets. A write, such as ``CREATE`` or the action of a ``write_action`` 

208 block, also passes it to ``before_action_commit`` and 

209 ``after_action_commit``. A read, ``GET_MANY`` or ``GET_ONE``, has no 

210 commit, so it reaches only ``authorize``. 

211 

212 Each view has a class ``Action`` that lists all its actions. It is this 

213 class, until a view adds actions of its own in a subclass:: 

214 

215 class PostView(fr.AsyncRestView): 

216 class Action(fr.Action): 

217 PUBLISH = "publish" 

218 

219 An ``Action`` class has only actions. An action has an UPPER_CASE name, 

220 and its value is that name in lower case. ``write_action`` takes only a 

221 value that the view's ``Action`` declares. A view with base classes that 

222 declare actions, such as a mixin, inherits from their ``Action`` classes 

223 too. 

224 """ 

225 

226 #: Read a list, as ``GET /`` does. A read has no commit. 

227 GET_MANY = "get_many" 

228 #: Read one row, as ``GET /{id}`` does. A read has no commit. 

229 GET_ONE = "get_one" 

230 #: Create a row, as ``POST /`` does. 

231 CREATE = "create" 

232 #: Update a row, as ``PATCH /{id}`` does. 

233 UPDATE = "update" 

234 #: Delete a row, as ``DELETE /{id}`` does. 

235 DELETE = "delete"

412def _check_actions(cls: type) -> None: 

413 """Refuse a view whose ``Action`` does not inherit from the ``Action`` of 

414 a base class. 

415 

416 Each class that declares ``Action`` adds actions, and a view's ``Action`` 

417 must have all of them: the view's own class, or a mixin's, or two bases 

418 that each declare one, where Python takes the first and drops the other. 

419 """ 

420 action = cls.Action # type: ignore[attr-defined] 

421 declared: list[tuple[type, Any]] = [] 

422 for klass in cls.__mro__: 

423 if "Action" not in vars(klass): 

424 continue 

425 value = vars(klass)["Action"] 

426 if all(value is not seen for _, seen in declared): 

427 declared.append((klass, value)) 

428 for klass, value in declared: 

429 if not (isinstance(value, type) and issubclass(value, Action)): 

430 raise RestlyConfigurationError( 

431 f"{cls.__name__}.Action{_origin(cls, klass)} does not inherit " 

432 "from fr.Action. Declare it as class Action(fr.Action)." 

433 ) 

434 missing = [ 

435 (klass, base) for klass, base in declared if not issubclass(action, base) 

436 ] 

437 if not missing: 

438 return 

439 # the classes to inherit from: the bases' Action classes, without one 

440 # that another of them already inherits from 

441 bases = [(klass, base) for klass, base in declared if klass is not cls] 

442 keep = [ 

443 _action_class_name(klass, base) 

444 for klass, base in bases 

445 if not any(other is not base and issubclass(other, base) for _, other in bases) 

446 ] 

447 raise RestlyConfigurationError( 

448 f"{cls.__name__}.Action{_set_by(cls, 'Action')} does not inherit from " 

449 f"{', '.join(_action_class_name(klass, base) for klass, base in missing)}. " 

450 "A view's Action has all the actions of its bases. " 

451 f"Declare it on {cls.__name__} with every base: " 

452 f"class Action({', '.join(keep)})." 

453 )

479

481 ``RestView`` and ``AsyncRestView``, in a sync and an async form. Subclass

495 #: resource. Restly builds :attr:`schema_response`, :attr:`schema_create` 

496 #: and :attr:`schema_update` from it. When a view sets none, Restly 

497 #: generates it from :attr:`model` with 

498 #: :func:`~fastapi_restly.schemas.derive_schema`. 

499 schema: ClassVar[type[pydantic.BaseModel]] 

500 #: The class of everything that goes out: the single responses, the 

501 #: items of the list response, and the fields the list params filter and 

502 #: sort on. The relationships it names are the ones the view loads. When 

503 #: a view sets none, Restly builds it with

513 #: The class of the ``PATCH`` body. When a view sets none, Restly builds 

514 #: it from the view's schema without its ``ReadOnly`` fields and without 

515 #: a primary key that the server generates, and makes every other field 

516 #: optional. It is named ``<Resource>Update``. A class that a view sets 

517 #: is used as it is.

520 #: you register needs it. A class that is not mapped raises 

521 #: :class:`~fastapi_restly.exc.RestlyConfigurationError` when Python 

522 #: creates the view class.

525 #: (a row outside it is 404). ``None`` (the default) falls back to the 

526 #: model's declared ``default_scope``; ``fr.clauses.UNSCOPED`` reads 

527 #: unscoped despite that default. Declaring a scope replaces the default, 

528 #: it does not stack on it; compose the replacement from the same leaves 

529 #: (``ItemClauses.trashed`` containing the tenant clause ``visible`` 

530 #: contains). A rule that must hold under every scope is a session-level 

531 #: ``with_loader_criteria``, not a view concern (see the Multi-Tenancy 

532 #: guide). See the Scopes guide for scopes. 

533 scope: ClassVar[WhereClause | None] = None 

534 #: The type of the ``{id}`` path parameter on the default routes. ``None`` 

535 #: (the default) takes the Python type of the model's primary key, and a 

536 #: composite key gets ``int``. Set a type to override it. Built-in item 

537 #: routes use Starlette's ``int`` or ``uuid`` path converter for those 

538 #: types. Integer paths accept non-negative digits. An unmatched value 

539 #: falls through to another route or returns 404, instead of 422. 

540 id_type: ClassVar[type[Any] | None] = None 

541 #: The routes that the view serves, such as 

542 #: ``(fr.ViewRoute.GET_MANY, fr.ViewRoute.GET_ONE)``: :class:`ViewRoute` 

543 #: values for the CRUD routes, or the names of route methods, also of a 

544 #: custom route. The view leaves out every other route, also a route that 

545 #: a base view gets later. The default, ``("*",)``, is every route. A 

546 #: subclass that sets its own value replaces the list of its base. A name 

547 #: that is not a route raises ``AttributeError`` when the view is 

548 #: registered. 

549 include_routes: ClassVar[Collection[str | ViewRoute]] = ("*",) 

550 #: The routes to leave out of the view, after :attr:`include_routes`, 

551 #: such as ``(fr.ViewRoute.DELETE,)``: :class:`ViewRoute` values for the 

552 #: CRUD routes, or the names of endpoint methods. A subclass that sets its 

553 #: own value replaces the list of its base. A name that is not a route 

554 #: raises ``AttributeError`` when the view is registered.

556 #: What a list route does with a query key that it does not read. 

557 #: ``"forbid"`` (the default) rejects the request with 422, so a typo in 

558 #: a filter key does not return more rows than the client asked for. 

559 #: ``"ignore"`` leaves the key out, as FastAPI does. The values are those of 

560 #: Pydantic's ``extra`` setting. The same rule applies to a ``QueryParams``
